01 / ABOUT

Who I am and how I work

For five years I've worked on software that has to stay up: internal platforms for live training events, participant-facing web applications, and the APIs underneath them. Most of that work has been in Go — REST and GraphQL services backed by MongoDB and MySQL, using goroutines to keep concurrent workloads efficient.

I'm equally comfortable on the other side of the request. I build Vue.js and Node.js frontends against Apollo GraphQL, with the Go backend generated through gqlgen — so I can carry a feature from schema design to the interface a user actually touches, without handing it off halfway.

On infrastructure, I build Docker images and orchestrate them with Kubernetes. Knowing how a service is deployed changes how I write it. My degree in Computer Engineering from the University of Bologna covered Big Data, Machine Learning and Apache Spark, which still shapes how I approach data-heavy problems.
