01 / about

Who I am and how I work

I'm a Full-Stack Developer based in Bologna, Italy. For the past five years I've worked on the kind of software that has to stay up: internal platforms for live training events, participant-facing web applications, and the APIs underneath them. Most of that work has been in Go — REST and GraphQL services backed by MongoDB and MySQL, using goroutines to keep concurrent workloads efficient.

I'm equally comfortable on the other side of the request. I build and maintain Vue.js and Node.js frontends against Apollo GraphQL, with the backend generated through gqlgen — so I can carry a feature from schema design to the interface a user actually touches, without handing it off halfway.

On infrastructure, I build Docker images and orchestrate them with Kubernetes. It's not a side interest: knowing how a service is deployed changes how I write it.

My degree in Computer Engineering and Science from the University of Bologna included Big Data, Machine Learning and Apache Spark, which still shapes how I think about data-heavy problems. More recently I've folded AI-assisted development into my daily workflow — used as a tool with judgment, not as autopilot.
