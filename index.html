about

I'm a Full-Stack Developer based in Bologna, Italy. For five years I've worked on software that has to stay up: internal platforms for live training events, participant-facing web apps, and the APIs underneath them — mostly in Go, with REST and GraphQL services backed by MongoDB and MySQL, using goroutines to keep concurrent workloads efficient.

I'm equally at home on the other side of the request: Vue.js and Node.js frontends against Apollo GraphQL, with the Go backend generated through gqlgen. I can carry a feature from schema design to the interface a user touches, without handing it off halfway.

On infrastructure, I build Docker images and orchestrate them with Kubernetes. Knowing how a service is deployed changes how I write it.
